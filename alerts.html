Follow the Azure portal steps

    Before you enable the rules
    1. Get read access to each target resource and action group. Get write access to the alert rule resource group.
    2. Check the resource tier and supported signals in Metrics. CPU and memory gateway metrics require an API Management v2 tier.
    3. Send approved test traffic. Confirm that each selected metric has recent data.
    4. Select or create an action group. Get approval for receivers. Test notification delivery.
    5. Check alert costs. Each dimension series can create a separate alert and charge.
    6. Agree on a separate no-data check. A metric rule does not prove health when samples stop.
